# A股右侧动量轮动策略设计

## 策略思路
基于多周期动量排序、趋势确认与组合风控的ETF轮动框架，针对A股的T+1、涨跌停及交易时段进行适配。

## 核心逻辑
> "右侧起步追强者，卖弱者，强变弱也要卖，不要在乎一时一票的盈亏，看整体。
> 一旦市场强者变少，弱者大面积增加，一般也就意味着要变天了，需要进行整体仓位的卖出。"

**为什么用ETF而不是个股？**
- A股5000+个股，实时数据获取慢、处理重
- ETF无涨跌停限制（除创业板相关），流动性好
- T+1下ETF轮动比个股更合理（避免当日买入后想跑跑不掉）
- 个股有黑天鹅、停牌、ST风险，ETF分散了

## 2. 动量评分模型
综合多时间维度动量，避免单一日期的噪音：

```
动量分 = 0.4 * 5日涨跌幅 + 0.3 * 10日涨跌幅 + 0.2 * 20日涨跌幅 + 0.1 * 60日涨跌幅
```

附加过滤器：
- **趋势确认**：收盘价 > 10日均线（确保不是暴跌中的反弹）
- **波动率惩罚**：20日波动率过高（>5%日均）降权，避免妖孽

## 3. 持仓规则
- 每次最多持有 **N=3** 只（分散但集中，抓最强）
- 只持有动量排名前N且动量分 > 0 的标的
- 如果前N名里有动量分 < 0 的，用**避险标的**替代
- **持仓不动**的条件：当前持仓仍在Top N+2范围内（减少摩擦成本）

## 4. 风控核心：强弱分化监测（变天信号）
这是策略的灵魂。监测整个ETF池的健康度：

### 4.1 强者减少信号
- 动量分 > 0 的标的数量 < 池子的40% → ⚠️ 预警
- 动量分 > 0 的标的数量 < 池子的25% → 🚨 清仓，全部转避险

### 4.2 均线空头信号
- 收盘价 > 20日均线的标的数量 < 30% → ⚠️ 预警
- 同时 < 15% → 🚨 清仓

### 4.3 市场整体动量
- 所有标的平均动量分连续3日下降 → ⚠️ 降仓50%
- 平均动量分由正转负 → 🚨 清仓

### 4.4 避险机制
一旦触发清仓信号：
- 全部卖出股票型ETF
- 买入货币基金（511880）或国债ETF（511010）
- 等待市场恢复（强者>50%且平均动量转正）再重新入场

## 5. 交易执行（T+1适配）
- **调仓频率**：每日收盘后计算信号，**次日14:50**执行交易
- 为什么是14:50？接近收盘，当日趋势基本确定，同时给足下单时间
- 如果当日某ETF涨停/跌停 → 跳过该标的交易，等次日
- **委托方式**：限价单，买一/卖一价，避免滑点

## 6. 再平衡细节
- 每只在仓标的**等权**（各33%左右）
- 买入新标的时，卖出旧标的的资金平分买入
- 如果只有1只达标，剩余资金进避险标的
- 如果0只达标，全部进避险

## 7. 回测与模拟
- 先用akshare取历史日线数据做回测
- 模拟盘跑1-2月，验证信号质量
- 对接券商API（如QMT、EasyTrade）前，先邮件/微信通知人工执行

## 8. 监控与报警
- 每日收盘后发日报：持仓、动量排名、强弱分化指标
- 触发风控时即时报警
- 记录每笔交易和当时的市场状态，用于复盘

## 9. A股交易约束与策略适配
| 维度 | A股（本策略） |
|------|-------------|
| 交易制度 | T+1，4h/日 |
| 标的数量 | 5000+个股 → 选14只ETF |
| 做空 | 难 → 用避险替代 |
| 涨跌停 | 10%/20% → ETF相对温和 |
| 数据获取 | akshare延迟15min |
| 轮动频率 | 日级/次日执行 |
